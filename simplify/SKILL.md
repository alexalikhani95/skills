---
name: simplify
description: Rewrite the previous assistant reply in much shorter, simpler language when the user asks to simplify it or make it short and sweet.
---

Rewrite the previous assistant message, or the text the user identifies, in plain, everyday language.

Keep the main point, essential facts, and any question or decision the user needs to answer. Cut filler, jargon, repetition, and unnecessary detail. Aim for one to three short sentences; use a brief list only when it makes the result easier to read.

Return only the rewritten message. Apply this to the requested text; ongoing style changes require a separate user request.
